Orphos

A high-performance Rust implementation of the Prodigal gene prediction algorithm for prokaryotic genomes. Runs entirely in your browser using WebAssembly.

Why Orphos

  • No installation required
  • Privacy first - sequences never leave your computer
  • Near-native speed via Rust and WebAssembly
  • Prodigal-compatible algorithm
  • Cross-platform - any modern browser

Features

  • Single genome and metagenomic modes
  • GFF3, GenBank, BED6, SCO, and GCA output
  • All standard genetic codes (tables 1-25)
  • Circular topology support
  • Closed ends, masked N-runs, gene models
